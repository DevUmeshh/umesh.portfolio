FEATURED — BUILD STORY

      
Cutting a manual AWS deploy down to one repeatable pipeline

      

        

          
Problem

          
At Sumago Infotech, releases across multiple projects were being deployed to AWS by hand — every deploy meant repeating the same EC2/S3 setup steps, which was slow and easy to get wrong.

        

        

          
Approach

          
Designed and maintained CI/CD pipelines with Git/GitHub, provisioned and configured the AWS infrastructure (EC2, S3, IAM), and wrote Linux shell scripts to automate environment setup and monitoring instead of doing it manually each time.

        

        

          
Result

          
Deployment workflows became streamlined and repeatable across projects, environment setup got noticeably faster, and I came away with hands-on exposure to the full lifecycle: code → build → test → deploy → monitor.
